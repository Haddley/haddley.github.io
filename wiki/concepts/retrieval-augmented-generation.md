**Summary.** Retrieval-augmented generation (RAG) provides Large Language Models with relevant context from a specific knowledge base to improve the accuracy and specificity of responses. I use RAG to ensure that models ground their answers in retrieved data rather than relying on internal memory, which can lead to hallucinations or outdated information.

## The idea
- RAG finds relevant text before the model generates an answer to provide necessary context.
- The system uses an embedding model to convert document chunks and queries into numerical representations for comparison.
- A separate model writes the final answer based on the retrieved passages to ensure the model only performs the task of reading the words.
- Grounding the system in a curated, scoped document set prevents the model from hallucinating facts or using ungrounded information.
- Context injection is more efficient than including an entire knowledge base in every prompt because it reduces costs and improves prompt efficiency.
